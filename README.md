# iPod UI

A React recreation of the classic iPod click wheel interface, including the rotating gesture control.

## Features

- Multiple navigable screens (menus, now playing, etc.)
- Functional click wheel: click the center button to select, click around the ring to move between tabs
- Drag-based rotation gesture — dragging the mouse around the wheel scrolls through menu items, just like the real hardware

## Stack

- React 17
- `zingtouch` / `react-native-gesture-handler` for gesture handling
- Create React App (react-scripts 5)

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
